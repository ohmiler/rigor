# RIGOR

เกมเอาตัวรอดในโลกซอมบี้แบบสมจริง มุมกล้องจากด้านบน ทำด้วย three.js
ตัวละครทุกตัว ทั้งผู้เล่นและซอมบี้ ขยับด้วย procedural animation ไม่มีคลิปแอนิเมชันเลย:
two-bone IK ให้มือกับขา, เท้าเหยียบพื้นแบบไม่ไถล, สปริงที่ลำตัวและมือ, รีโหลดแบบแบ่งขั้นที่รอให้มือแตะเป้าจริง และแรงถีบปืน

แผนงานดูได้ที่ [ROADMAP.md](ROADMAP.md)

**เล่นได้ที่ https://ohmiler.github.io/rigor/** (ต้องใช้คีย์บอร์ดกับเมาส์)
เว็บอัปเดตเองทุกครั้งที่ push ขึ้น `main` ผ่าน GitHub Actions ([.github/workflows/deploy.yml](.github/workflows/deploy.yml))

## เปิดเกม

ต้องมี Node.js

```bash
npm install
npm run dev
```

แล้วเปิด http://localhost:5173

### เครื่องมือพัฒนา

บน dev server (`npm run dev`) แผง Levers, ข้อความ debug, ปุ่ม Lab และปุ่มทดสอบ (N เกิดซอมบี้, T สโลว์โมชัน, B โครงกระดูก) จะเปิดอยู่เสมอ
ในเวอร์ชันบนเว็บจะซ่อนไว้ เปิดได้โดยเติม `?dev` ท้ายลิงก์ เช่น https://ohmiler.github.io/rigor/?dev

### Lab ทดสอบท่าทาง

http://localhost:5173/lab.html (หรือกดปุ่ม Lab มุมซ้ายบนในเกม)

พื้นโล่งพร้อมสิ่งกีดขวางทดสอบ 6 แบบ มีกล้องหมุนรอบได้ timeline ให้ลากดูทีละเฟรม ภาพซ้อน (onion skin)
เส้นทางของมือ เท้า สะโพก แก้ keyframe ของท่าปีนกับกระโดดข้ามได้สด และเทียบท่าใหม่กับท่าเดิม (A/B)
กด **Save** แล้วเกมจะใช้ keyframe ชุดนั้นทันที (เก็บไว้ในเบราว์เซอร์) ถ้าอยากให้เป็นค่าถาวรในโค้ด
ให้ Copy JSON แล้วใส่ลงใน `src/traversal-keys.js`

## Replay

ทุกรอบมี seed ของตัวเอง (ตำแหน่งและชนิดซอมบี้ ของที่วางตามถนน การสุ่มทุกอย่างในเกมมาจาก seed นี้) และเกมจำลองทีละขั้นคงที่ 120 ขั้นต่อวินาที ไฟล์ replay จึงเก็บแค่ seed กับปุ่มที่กดในแต่ละขั้น ไม่กี่ KB ต่อนาที แล้วเล่นซ้ำได้ตรงเป๊ะ

- หลังตายหรือรอด กด **Y** ดูซ้ำ หรือ **U** บันทึกเป็นไฟล์ `.json` ระหว่างเล่นกด **F8** บันทึกถึงตอนนั้นได้เลย
- เปิดไฟล์ได้จากปุ่ม "Watch a replay file…" ในหน้าแรก หรือลากไฟล์มาวางบนหน้าเกม
- ถนนสร้างจาก seed คงที่ ทุกเครื่องจึงได้ถนนเดียวกัน ไฟล์ replay เปิดที่เครื่องไหนก็ตรง
- ไฟล์เก็บค่า Levers ตอนเล่นไว้ด้วย ตอนดูจึงใช้ค่าเดียวกัน แล้วคืนค่าของเราหลังดูจบ
- ทุกวินาทีจะเทียบสถานะของโลกกับที่บันทึกไว้ ถ้าไม่ตรง (เช่นไฟล์มาจากเกมเวอร์ชันอื่น) แถบ replay จะบอกว่าเพี้ยนตั้งแต่วินาทีไหน
- `?seed=123` ต่อท้าย URL = เล่นด้วย seed นั้นทุกรอบ (ซอมบี้และของชุดเดิม)

## โมเดลฉาก (Blender)

รถ ถังขยะ และแบริเออร์สร้างใน Blender ด้วยสคริปต์ [art/build_props.py](art/build_props.py) แล้ว export เป็น `public/models/*.glb` (รวมกันราว 100 KB) เกมโหลดมาวางทับกล่องเดิมใน `level.js` ส่วนกล่องเดิมยังอยู่แบบซ่อนไว้ เป็นตัวรับกระสุนและเป็นรูปทรงที่ใช้ปีน กระโดดข้าม และยืน ถ้าโหลดโมเดลไม่ได้ก็จะเห็นกล่องแทน

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run models` | สร้างโมเดลใหม่จากสคริปต์ (หา Blender จาก `BLENDER_PATH` หรือที่ติดตั้งปกติ) |
| `blender --background --python art/preview.py -- out.png` | เรนเดอร์ภาพโมเดลเรียงกันไว้ดูโดยไม่ต้องเปิดเกม |

- ทุกขนาดในสคริปต์ใช้พิกัดเกม (x ขวา, y ขึ้น, z หน้า หน่วยเมตร) และต้องตรงกับกล่องชนใน `level.js`
- วัสดุชื่อ `Paint` ของรถ เกมจะเปลี่ยนสีให้แต่ละคัน
- **หน้าตึก** ([art/build_street.py](art/build_street.py)) เป็นชิ้นสำเร็จรูปกว้างช่องละ 3 ม.: หน้าร้าน (กระจก/แตก/ประตูม้วน/ตอกไม้/ประตู) หน้าต่างชั้นบน (ปกติ/แอร์/แตก/ตอกไม้/เปิดไฟ) ขอบชั้น คิ้วตึก เสาขอบ บันไดหนีไฟ กันสาด และของบนหลังคา `props.js` เอามาต่อตามความยาวและจำนวนชั้นของแต่ละตึก (เลือกจากตำแหน่งตึก หน้าตาจึงเหมือนเดิมทุกครั้ง) แล้วรวมทั้งถนนเป็นก้อนเดียวต่อวัสดุ ไม่ให้ draw call เพิ่ม ชิ้นยื่นจากผนังไม่เกิน 0.7 ม. เพื่อไม่บังทางเท้าจากมุมกล้อง วัสดุ `Wall` `Sign` `Awning` เกมใส่สีให้ตามตึก
- **ตัวผู้เล่น** ([art/build_character.py](art/build_character.py)) ปั้นเป็นชิ้นแยกตามช่องของร่างกาย (สะโพก อก หัว ต้นแขน แขนท่อนล่าง มือ ต้นขา หน้าแข้ง เท้า นิ้วเท้า) แต่ละชิ้นปั้นในกรอบพิกัดของช่องนั้น (ดูคำอธิบายบนหัวไฟล์) เกมยังขยับร่างเองทั้งหมด ชิ้นจากโมเดลแค่เข้าไปแทนแคปซูลในช่อง ท่าเดิน ragdoll ฉีกร่าง และโหมดโครงกระดูกจึงใช้ได้เหมือนเดิม
- **ซอมบี้** อยู่ในไฟล์ `zombie.glb` ไฟล์เดียว: ชิ้นพื้นฐานใช้ชื่อช่อง ชิ้นเฉพาะแบบตั้งชื่อ `<แบบ>_<ช่อง>` เช่น `brute_chest` (ห้ามใช้ `:` เพราะ three.js ตัดทิ้ง) ตัว brute หนาขึ้นตามค่า bulk ในเกม
- วัสดุชื่อ `Skin` `Shirt` `Pants` `Shoes` `Cap` จะใช้สีของตัวละครแต่ละตัว (ซอมบี้สุ่มสีเอง ตัวที่หัวล้านจะซ่อนชิ้นที่เป็น Cap) วัสดุอื่นใช้สีจาก Blender
- จะแก้ด้วยมือใน Blender ก็ได้: เปิดสคริปต์ในแท็บ Scripting แล้วกด Run แต่ถ้ารัน `npm run models` อีกครั้ง ไฟล์ที่แก้มือจะถูกเขียนทับ

## โครงสร้างโค้ด

- `src/humanoid.js` — ระบบร่างกายกลาง: เดิน, IK, สปริงลำตัวและมือ
- `src/player.js` — ผู้เล่น: ปืน แรงถีบ รีโหลด
- `src/zombie.js` — ซอมบี้: AI, ท่าเดินกะเผลก, โดนยิง, ล้มตาย
- `src/characters.js` — โหลดโมเดลตัวละครจาก Blender ให้ร่างสวม (`Humanoid.dress`)
- `src/props.js` — โหลดโมเดลจาก Blender มาวางทับกล่องในฉาก
- `src/replay.js` — การสุ่มแบบมี seed, บันทึกและเล่นซ้ำอินพุตทีละขั้น, ตรวจว่า replay เพี้ยนไหม
- `src/post.js` — ภาพหลังเรนเดอร์: ไฟเรืองแสง ขอบมืด ฟิล์มเกรน จอแดงและสีเพี้ยนตอนโดนกัด สีซีดและขอบแดงเต้นตามหัวใจตอนเลือดน้อย (เครื่องที่ช้าต่ำกว่า 25 fps จะปิดเองอัตโนมัติ ปรับได้ในแผง Look ของ `?dev`)
- `src/nav.js` — หาทาง: ตารางช่องเดินได้/ไม่ได้ + flow field ให้ซอมบี้อ้อมรถและแนวกั้นมาหาเรา
- `src/traversal.js` / `src/traversal-keys.js` — ระบบท่าปีนและกระโดดข้าม และ keyframe ของท่า
- `src/level.js` — ฉากถนน การชน ความสูงพื้น การหาขอบที่ปีนได้
- `src/grapple.js` / `src/gore.js` — ระบบโดนจับ ดิ้น กัด และเลือด/เศษร่าง
- `src/lab/` — หน้า lab ทดสอบท่าทาง
- `src/rig-utils.js` — สูตร IK, สปริง และเครื่องมือคณิตศาสตร์
- `src/effects.js` — แสงวาบปากกระบอก, เส้นกระสุน, ประกายไฟ/เลือด
- `src/params.js` — ค่าเริ่มต้นของ lever ทุกตัว
- `src/main.js` — ฉาก กล้อง การรับปุ่ม การชนกัน
