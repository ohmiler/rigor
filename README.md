# RIGOR

เกมเอาตัวรอดในโลกซอมบี้แบบสมจริง มุมกล้องจากด้านบน ทำด้วย three.js
ตัวละครทุกตัว ทั้งผู้เล่นและซอมบี้ ขยับด้วย procedural animation ไม่มีคลิปแอนิเมชันเลย:
two-bone IK ให้มือกับขา, เท้าเหยียบพื้นแบบไม่ไถล, สปริงที่ลำตัวและมือ, รีโหลดแบบแบ่งขั้นที่รอให้มือแตะเป้าจริง และแรงถีบปืน

แผนงานดูได้ที่ [ROADMAP.md](ROADMAP.md)

**เล่นได้ที่ https://ohmiler.github.io/rigor/** (ต้องใช้คีย์บอร์ดกับเมาส์)
เว็บอัปเดตเองทุกครั้งที่ push ขึ้น `main` ผ่าน GitHub Actions ([.github/workflows/deploy.yml](.github/workflows/deploy.yml))

## เปิดเกม

ต้องมี Node.js

```bash
npm install
npm run dev
```

แล้วเปิด http://localhost:5173

### เครื่องมือพัฒนา

บน dev server (`npm run dev`) แผง Levers, ข้อความ debug, ปุ่ม Lab และปุ่มทดสอบ (N เกิดซอมบี้, T สโลว์โมชัน, B โครงกระดูก) จะเปิดอยู่เสมอ
ในเวอร์ชันบนเว็บจะซ่อนไว้ เปิดได้โดยเติม `?dev` ท้ายลิงก์ เช่น https://ohmiler.github.io/rigor/?dev

### Lab ทดสอบท่าทาง

http://localhost:5173/lab.html (หรือกดปุ่ม Lab มุมซ้ายบนในเกม)

พื้นโล่งพร้อมสิ่งกีดขวางทดสอบ 6 แบบ มีกล้องหมุนรอบได้ timeline ให้ลากดูทีละเฟรม ภาพซ้อน (onion skin)
เส้นทางของมือ เท้า สะโพก แก้ keyframe ของท่าปีนกับกระโดดข้ามได้สด และเทียบท่าใหม่กับท่าเดิม (A/B)
กด **Save** แล้วเกมจะใช้ keyframe ชุดนั้นทันที (เก็บไว้ในเบราว์เซอร์) ถ้าอยากให้เป็นค่าถาวรในโค้ด
ให้ Copy JSON แล้วใส่ลงใน `src/traversal-keys.js`

## ทดสอบ

| คำสั่ง | ทำอะไร |
|---|---|
| `npm test` | ทดสอบระบบของเกมแบบไม่เปิดจอ (ไม่ถึงวินาที): เท้าไม่จม/ไม่ไถล, ขาไม่ไขว้, ก้าวขึ้นขั้น, ตก, ปืน, การเล็ง, บาดแผล, ศพ, ท่าคลาน, ซอมบี้หาทางอ้อมสิ่งกีดขวาง |
| `npm run test:watch` | รันทดสอบใหม่เองทุกครั้งที่แก้ไฟล์ |
| `npm run test:e2e` | build แล้วเปิดเกมในเบราว์เซอร์จริง: โหลดได้ เริ่มได้ เดินได้ ยิง/รีโหลด/สลับอาวุธได้ ไม่มี error (ครั้งแรกรัน `npx playwright install chromium` ก่อน) |
| `npm run typecheck` | ตรวจชนิดข้อมูลของโค้ดด้วย TypeScript (โค้ดยังเป็น JavaScript) |
| `npm run check` | รันทั้งหมดข้างบน |

ทุกครั้งที่ push ขึ้น `main` GitHub Actions จะรันทั้งหมดก่อน ถ้าไม่ผ่าน เว็บจะไม่ถูกอัปเดต (ยังเป็นเวอร์ชันล่าสุดที่ผ่าน)
ชุดทดสอบอยู่ใน `tests/` (ใช้ `tests/world.js` สร้างโลกจำลองไม่มีจอ) และ `e2e/`
การสุ่มในการทดสอบใช้ seed คงที่ ผลจึงออกเหมือนเดิมทุกครั้ง

## โครงสร้างโค้ด

- `src/humanoid.js` — ระบบร่างกายกลาง: เดิน, IK, สปริงลำตัวและมือ
- `src/player.js` — ผู้เล่น: ปืน แรงถีบ รีโหลด
- `src/zombie.js` — ซอมบี้: AI, ท่าเดินกะเผลก, โดนยิง, ล้มตาย
- `src/nav.js` — หาทาง: ตารางช่องเดินได้/ไม่ได้ + flow field ให้ซอมบี้อ้อมรถและแนวกั้นมาหาเรา
- `src/traversal.js` / `src/traversal-keys.js` — ระบบท่าปีนและกระโดดข้าม และ keyframe ของท่า
- `src/level.js` — ฉากถนน การชน ความสูงพื้น การหาขอบที่ปีนได้
- `src/grapple.js` / `src/gore.js` — ระบบโดนจับ ดิ้น กัด และเลือด/เศษร่าง
- `src/lab/` — หน้า lab ทดสอบท่าทาง
- `src/rig-utils.js` — สูตร IK, สปริง และเครื่องมือคณิตศาสตร์
- `src/effects.js` — แสงวาบปากกระบอก, เส้นกระสุน, ประกายไฟ/เลือด
- `src/params.js` — ค่าเริ่มต้นของ lever ทุกตัว
- `src/main.js` — ฉาก กล้อง การรับปุ่ม การชนกัน
