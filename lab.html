วิธีใช้ Lab (กด H เปิด/ปิด)

      
Lab ไว้ดูและจูนท่าทาง ถ้าจะเล่นเกมกด “← back to the game” มุมซ้ายบน

      

        
เปลี่ยนสิ่งกีดขวาง

        
แผงขวา → Test → Obstacle · ช่อง Who เปลี่ยนเป็นซอมบี้

        
ดูท่าทีละจังหวะ

        
ลากแถบด้านล่าง · ขีดเหลือง = keyframe (คลิกได้) · Space เล่น/หยุด · , . ทีละเฟรม

        
กล้อง

        
ลากเมาส์หมุน · ล้อเมาส์ซูม · ปุ่ม Quarter / Side / Front / Back

        
ภาพซ้อนและเส้นทาง

        
แผงขวา → Display · เหลือง สะโพก · เขียว/ฟ้า มือซ้าย/ขวา · แดง/ชมพู เท้าซ้าย/ขวา

        
เดินเล่นเอง

        
Free walk → ติ๊ก Walk around · WASD เดิน · Shift วิ่ง · Space ปีน · R รีโหลด

        
แก้ท่า

        
Keys → เปิด Key แล้วลากค่า · เห็นผลทันที · Save = เกมใช้ท่านี้ · Reset to code = กลับค่าเดิม

        
ตรวจท่าอัตโนมัติ

        
Test → Check all moves · บอกว่ามือเอื้อมไม่ถึง ขายืดเกิน หรือข้อต่อจมเข้าไปในของ ที่กี่ % ของท่า (✓ = ผ่าน)

        
เทียบท่า

        
Compare A/B → Set baseline แล้วแก้ต่อ · ท่าเดิมจะซ้อนเป็นสีส้ม
